# Schematic Demo Declaration

This file is part of the ArchaeoForge training project for Babylon, approximately 570 BCE.

The following starter elements are schematic placeholders and are not archaeological evidence:

1. The local coordinates and relative placement of the river, walls, palace mass, residential districts, Etemenanki, Ishtar Gate, and Processional Way.
2. The density, dimensions, heights, courtyards, street access, and orientation of procedural houses.
3. The full height, upper-stage proportions, summit shrine, and stair configuration used by the Etemenanki preview.
4. The wall height, thickness, circuit, towers, and gate relationships used by the preview.
5. The riverbank profile and the simple palace volume.

These elements must remain Evidence Class C, needs review, and preview-only until replaced by georeferenced plans, surveyed remains, published measurements, and specialist review. The visual output must not be described as a complete scholarly reconstruction.
