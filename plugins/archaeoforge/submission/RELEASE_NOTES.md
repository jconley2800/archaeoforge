# Initial public release notes

ArchaeoForge 0.1.0 is an initial skills-only plugin submission. It packages a reusable evidence-controlled historical-site reconstruction workflow, read-only project and CLI discovery, Blender pipeline guidance, two explicit image-finishing modes, candidate-only image generation, and hash-bound provenance registration.

The plugin has no MCP server, hosted service, authentication, telemetry, or demo credentials. CLI-backed tests use the separately installed MIT-licensed ArchaeoForge engine. Built-in Codex image generation is used interactively; optional API operations require the user's own OpenAI API key and explicit configuration.
