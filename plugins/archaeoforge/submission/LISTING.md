## Long description

ArchaeoForge helps researchers and creators build evidence-controlled reconstructions of lost or transformed historical places. It guides Codex through source ingestion, human review, dated GeoJSON geometry, deterministic scene compilation, Blender rendering, and explicit uncertainty reporting. For final imagery, it distinguishes strict geometry-preserving edits from broad historical-scene interpretation, uses a separate image-generation candidate, and publishes only through a hash-bound provenance gate. Generated images remain non-authoritative presentation products. The supported end-to-end workflow is currently Linux-first, requires Codex and ArchaeoForge 0.1.0 or a matching checkout, and has separate Blender and optional OpenAI API requirements.
