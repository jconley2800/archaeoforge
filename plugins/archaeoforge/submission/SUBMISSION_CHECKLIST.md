# Public submission checklist

## Prepared

- [x] Skills-only plugin file tree
- [x] Valid plugin manifest
- [x] Clear skill triggers and scoped task instructions
- [x] Referenced scripts and documentation
- [x] Production logo
- [x] Listing copy and starter prompts
- [x] Five positive and three negative reviewer test cases
- [x] Initial release notes
- [x] MIT license
- [x] Draft website, support, privacy, terms, and security documents
- [x] Local plugin and skill validation

## Publisher must complete

- [ ] Create and publish `https://github.com/jconley2800/archaeoforge` or replace every draft URL with the final public URLs.
- [ ] Confirm the public repository includes the ArchaeoForge engine required by the skill.
- [ ] In the OpenAI Platform organization, grant the submitter Apps Management write access.
- [ ] Complete individual or business verification for the identity that will publish the plugin.
- [ ] Review and accept the privacy policy, terms, availability regions, and policy attestations.
- [ ] Upload the final skill bundle in the plugin submission portal as **Skills only**.
- [ ] Submit at least the five positive and three negative cases in `TEST_CASES.md`.
- [ ] Submit for review.
- [ ] After OpenAI approval, select Publish in the portal.
