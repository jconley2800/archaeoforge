# Security policy

## Supported version

Security fixes are applied to the latest published version of the ArchaeoForge plugin and engine.

## Reporting a vulnerability

Do not include secrets, private research sources, restricted site coordinates, or personal data in a public issue. Open a minimal report at <https://github.com/jconley2800/archaeoforge/issues> and request a private follow-up channel when disclosure would expose sensitive information.

## Security model

The plugin is skills-only and has no hosted service. It can instruct Codex to run the local ArchaeoForge CLI and modify user-authorized project files. Users should review commands before authorizing destructive replacements, keep API keys outside chat, and treat imported project files as untrusted until reviewed.
